# Проверка после правки

1. Запусти `./gradlew :server:test :shared:jvmTest`. В отчёт запиши, прошло или упало, и имя упавшего теста.
2. Прочитай `challenge/day3/SMOKE.md`. Если появился новый экран или ручка, которую видит человек, допиши сценарий в этот файл и не удаляй старые.
3. Подними сервер и пройди сценарии в браузере. На каждом шаге сохрани скриншот. Для шага, который не про интерфейс, запиши код ответа.
4. Собери один отчёт: код-тесты, каждый smoke-сценарий (прошёл или нет), скриншот, где сломалось.
5. Модель помощника остаётся на S1. Адрес `10.10.0.220` для этого прогона не используй.
