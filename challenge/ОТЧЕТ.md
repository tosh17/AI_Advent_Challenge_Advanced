# Отчёт по требованиям

Правила, которые читает Cursor: `.cursorrules` и `.cursor/rules/project.mdc`. Текст один и тот же, это v2. Снимок v1 — `challenge/rules-v1.md`, снимок v2 на момент второй генерации — `challenge/rules-v2.md`.

Файлы Claude и Copilot убраны: на работу в Cursor они не влияют.

## Что внутри правил

Пять примеров, как писать:

1. `Agent.handle` только передаёт фразу модели и исполняет её вызовы.
2. Тонкий `post /sessions/{id}/messages`.
3. `ExposedActivityStore.find` через DSL, без SQL-строки.
4. `activities_log` всегда пишет `ActivityKind.Log`.
5. Тест `AgentTest.wordsDoNotSelectTools`: слова «спринт» и «завтра» сами инструменты не вызывают.

Запреты:

1. Разбор фразы через `contains("спринт")`.
2. `Any` и сырой JSON в домене, роуте и агенте.
3. `println` и `System.out` в `src/main`.
4. Прямой SQL в Kotlin.
5. Пустой `catch`, звёздный импорт, зашитые ключи Jira и адреса.

Шаблон файла: пакет, три группы импортов (`kotlin`, сторонние, `app.work`), класс с одним действием. Для HTTP рядом образец `days.load(raw)`.

## Боевая задача

Промпт один, без уточнений: `challenge/prompt.txt`. Задача — `GET /api/days/{date}`. Его дважды отдали ассистенту, между прогонами текст промпта не менялся.

| | Генерация 1, правила v1 | Генерация 2, правила v2 |
|---|---|---|
| Скомпилировалось | да | да |
| Тесты и проверка запретов | `:server:test` прошёл, включая `SourceRulesTest` | `:server:test` и `:shared:jvmTest` прошли |
| Стиль | endpoint и `400` на месте, но роут сам звал `ActivityStore`, `BadDate` лежал в `Routes.kt`, в тестах два `idleTurns` и прямой `Database.connect` | роут только вызывает `days.load(raw)`, чтение в `StoredDays`, `BadDate` рядом со `StatusPages`, один `idleTurns`, база через `connect()`, беклог без даты явно проверен |

Отдельного ktlint или detekt в проекте нет. Запреты `println`, SQL и `.contains(` в агенте и роуте проверяет `SourceRulesTest` вместе с тестами.

## Усиление

После первой генерации из правил убрана фраза, по которой роут мог сам брать `ActivityStore`. Вместо неё вставлен образец `days.load(raw)`, исключение даты привязано к `Module.kt`, тест расписан: `connect()`, один `idleTurns`, беклог с `onDate = null`.

Тот же промпт повторён. Разница:

- сырые диффы: `challenge/gen1.diff`, `challenge/gen2.diff`, `challenge/gen1-vs-gen2.diff`
- исходники двух генераций: `challenge/gen1/`, `challenge/gen2/`
- разбор словами, потому что unified diff похож: `challenge/ДИФЫ.md`
- ход эксперимента: `challenge/REPORT.md`

Скриншотов нет.

## Что сильнее всего повлияло

1. Убрана двусмысленная фраза «роут делегирует `Turns` или `ActivityStore`». Из-за неё первая генерация отдала базу в роут.
2. В правила вставлен готовый вид ветки из двух строк, а не только запрет.
3. `BadDate` и `StatusPages` собраны в `Module.kt`.
4. Тест описан конкретно: `connect()`, один `idleTurns`, беклог без даты и отдельная проверка summary.
