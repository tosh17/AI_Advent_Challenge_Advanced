# Рабочий помощник

Один человек пишет свободно. Смысл фразы решает модель и вызывает инструменты MCP. Код слова в тексте не ищет.

## Тесты

```
./gradlew :server:test :shared:jvmTest
```

## HTTP

Ручки ниже сняты с `server/src/main/kotlin/app/work/server/Routes.kt`.

| Метод | Путь | Ответ |
| --- | --- | --- |
| GET | `/api/health` | `{"status":"ok"}` |
| GET | `/api/days/{date}` | Журнал и план на `YYYY-MM-DD`. Неверная дата — `400` и `{"error":"Неверная дата"}`. Беклог и спринт в этот ответ не входят |
| GET | `/api/sprint` | Текущий спринт, поле `items` |
| GET | `/api/backlog` | Беклог, поле `items` |
| GET | `/api/search?q=` | Уже записанное по тексту, номеру или ссылке. Пустой `q` — `400` и `{"error":"Пустой запрос"}` |
| POST | `/api/sessions` | Новая сессия, поле `id` |
| POST | `/api/sessions/{id}/messages` | Тело `{"text":"..."}`. Ответ — реплика модели и вызовы инструментов |
